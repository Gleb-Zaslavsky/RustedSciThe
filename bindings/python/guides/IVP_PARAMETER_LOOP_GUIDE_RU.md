# Независимый цикл параметров IVP

Используйте `solve_parameter_loop(y0, parameter_vectors)`, если одну
подготовленную IVP-модель нужно решить для нескольких наборов параметров.
Метод доступен у BDF, Backward Euler, LSODE2 и Radau, а также у
`PreparedStiffSolver` после выбора маршрута.

Каждая точка запускает новое интегрирование с одним и тем же `y0` и на
настроенном временном интервале. Подготовленные символьные/AOT callbacks
переиспользуются, но предыдущее конечное состояние не становится начальным
приближением. Это sweep параметров, а не continuation.

Список `IvpParameterLoopPoint` сохраняет порядок, индекс и исходный вектор
параметров. При успехе обычный detached-результат доступен через `.solution`;
его NumPy-траектория и нативная телеметрия остаются на объекте решения. При
ошибке `.error` содержит типизированное исключение с контекстом `stage`,
`solver`, `route` и `native_kind`; следующие точки всё равно выполняются.
Radau возвращает данные согласно output policy: Dense — границы принятых
шагов, Sampled — запрошенные моменты, FinalOnly — только последнюю строку.

См. [`ivp_parameter_loop.py`](../examples/ivp_parameter_loop.py) для выбора
прямого solver-а и [`stiff_api_parameter_loop.py`](../examples/stiff_api_parameter_loop.py)
для общего фасада.
