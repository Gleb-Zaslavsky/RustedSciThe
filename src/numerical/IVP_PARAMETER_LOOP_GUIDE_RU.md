# Независимый цикл параметров для IVP

Солверы первого уровня для жёстких IVP (BDF, Backward Euler, LSODE2 и Radau)
предоставляют `try_solve_parameter_loop(y0, parameter_vectors)`. Подготовленная
символьная/AOT-модель переиспользуется, но каждый набор параметров запускает
новое интегрирование с тем же `y0` и на том же настроенном интервале.
Предыдущее конечное состояние не используется.

Для каждой точки отчёт хранит индекс и исходный вектор параметров. При успехе
сохраняются `x_mesh` и значения состояний по строкам с формой
`(time_points, state_variables)`, а также нативный снимок телеметрии. При
ошибке сохраняется исходная типизированная ошибка; остальные наборы всё равно
обрабатываются. Некорректные векторы остаются локальными отказами отдельных
точек.

У Radau возвращаемая ось определяется выбранной политикой вывода: Dense хранит
границы принятых шагов, Sampled — заданные моменты, FinalOnly — только конечную
точку. Поэтому общий результат отражает сохранённый вывод solver-а, а не
восстанавливает внутреннюю сетку, отброшенную политикой.

StiffAPI предоставляет ту же операцию после подготовки маршрута. Для
solver-специфичных настроек используйте прямые API. Примеры находятся в
`examples/bdf_parameter_loop.rs`, `examples/be_parameter_loop.rs`,
`examples/lsode2_parameter_loop.rs`, `examples/radau_parameter_loop.rs` и
`examples/stiff_api_parameter_loop.rs`.
